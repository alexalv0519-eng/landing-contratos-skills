# Landing Page & Skill de Redacción de Contratos

## Descripción
Proyecto de integración de Inteligencia Artificial aplicada al ejercicio jurídico en Colombia mediante **Gemini Skills**, diseñado para la generación automatizada y estandarizada de Contratos de Prestación de Servicios Profesionales.

## Estructura del Entregable
- `index.html`: Estructura semántica de la Landing Page.
- `styles.css`: Estilos visuales adaptables (responsive design).
- `README.md`: Documentación técnica del proyecto.
- **Skill Gemini:** `redactar-contrato-servicios` estandarizada sobre plantilla institucional en PDF.

## Requisitos e Instalación
1. Abrir el proyecto en **OpenCode** o cualquier editor de código.
2. Abrir el archivo `index.html` en el navegador para visualizar la Landing Page.
